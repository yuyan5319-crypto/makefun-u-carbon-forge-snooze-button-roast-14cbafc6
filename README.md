A one-line roast of an alarm clock that rings at 6 AM on a Saturday, written for the make.fun "Snooze Button Roast" bounty. The program writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

> My alarm clock rang at 6 AM on a Saturday like a rooster that got fired from the farm and is taking it out on me.

## Run

```sh
node main.ts
```

Node 22 or later, no dependencies.
